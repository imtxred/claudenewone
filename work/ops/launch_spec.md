## 1.1. НОВУЮ КАМПАНИЮ НЕ СОБИРАТЬ. ДУБЛИРОВАТЬ СУЩЕСТВУЮЩУЮ

**Правило владельца от 19.08.** Запуск нового варианта — это всегда копия рабочей кампании, а не сборка с нуля. Дешевле, быстрее и переносит то, что при пересборке теряется: ID креативов, пиксель, атрибуцию и **накопленные реакции, комментарии и репосты под объявлением**. Свежесобранное объявление стартует с нулевым социальным доказательством и проигрывает.

### В Ads Manager

Кнопка **«Дублировать»** на кампании. Дальше два диалога.

**Диалог «Продублируйте кампанию» — снять ВСЕ галочки, включая верхнюю «Применить рекомендации».** Ни одной. Facebook показывает рядом с ними обещания вида «снижение цены за результат на 23%» — это не наши данные, а его модель, и каждая из рекомендаций ломает проверенную связку:

| Рекомендация | Что ломает |
|---|---|
| Места размещения в Instagram (3) | главное правило — только `facebook / feed / mobile` |
| Параметр Advantage+ для бюджета | переводит на CBO, а мы работаем на ABO |
| Сайт и моментальные формы | меняет тип конверсии и точку замера |
| Добавить видео | меняет креатив, который и есть предмет теста |
| Креатив Advantage+ | отдаёт алгоритму кадрирование, текст и наложения |

**Диалог «Дублировать кампанию».** Число копий — 1. Галочку **«Показывать существующие реакции, комментарии и репосты в новых объявлениях» оставить включённой** — ради неё всё и затевается. A/B-тестирование не включать. Нажать «Дублировать» и больше ничего не трогать.

**Потом, уже в копии,** менять только четыре вещи: имя, бюджет на адсетах, ссылку в креативах, отложенный старт.

### Через API

`POST /<campaign_id>/copies` с `deep_copy=true` и `status_option=PAUSED`, затем правки в копии. Не создавать кампанию, адсеты и креативы по отдельности — это и дороже по токенам, и теряет социальное доказательство.

## 5. ПРАВИЛО ОТСЕЧКИ И МАРКЕР TEST

### Маркер

- **Новая кампания создаётся со словом `TEST` в названии.** Формат: `(ДД ММ) ГЕО тип вариант (метка) TEST`
- Прожила больше двух суток и дала результат → **`TEST` снимается**, кампания переходит под контроль по CPL
- **Вы гасите кампанию сами → снимаете `TEST` руками.** После этого её никто не поднимет: правило перезапуска работает только по кампаниям с маркером

Зоны ответственности:

| | Кто ведёт | Что делает |
|---|---|---|
| **С маркером TEST** | нативные автоправила Facebook | гасит пустышки, даёт один второй заход, убивает навсегда |
| **Без маркера** | моя Routine в 04:04 | снимает маркер у выпускников, гасит по CPL. **Никогда ничего не включает** |

### Сама отсечка

Тест кампании стоит **$30–40, не больше**. Дальше не тратим ни при каких условиях.

**День 1.** Открут $15 накопленным итогом:
- есть результаты → живёт, судим по CPL
- **ноль результатов → пауза**, перезапуск на следующий день в 04:00 GMT+3

**День 2 (единственный второй заход).**
- есть результаты → живёт
- **ноль результатов → выключение навсегда**

**Отдельно, не дожидаясь $15:** аномальные CPM или CPC на старте — самостоятельное основание гасить.

**Почему это работает.** При целевом CPL $10 открут $15 ожидает 1.5 лида. Вероятность нуля у рабочей кампании — 22%, поэтому один нулевой день ничего не доказывает и второй заход обязателен. Два нуля подряд — 5%. Это и есть цена правила: теряем примерно одну рабочую связку из двадцати, но не платим $150 за каждую пустышку. Для Латинской Америки при цели $3 один нулевой день на $15 — это уже 0.7%, там второй заход почти формальность.

## 9. Автоматика

### Нативные автоправила Facebook — создаются руками в Ads Manager

**Правило 1 — «Гасим пустышки»**
- Применить к: все активные кампании, **название содержит `TEST`**
- Условие: расход **за всё время ≥ $15** И результаты **за всё время = 0**
- Действие: выключить кампанию
- Частота: каждые 30 минут

**Правило 2 — «Один второй заход»**
- Применить к: все выключенные кампании, **название содержит `TEST`**
- Условие: расход **за всё время < $30** И результаты **за всё время = 0**
- Действие: включить кампанию
- Расписание: ежедневно в 04:00

Двухударная логика получается из условия на **пожизненный** расход, без памяти о состоянии:
день 1 → $15, ноль, гаснет → 04:00 видит $15 < $30, поднимает → день 2 → $30, ноль, гаснет → 04:00 видит $30, **не поднимает больше никогда**.

**Правило 3 — по CPL (опционально)**
- Европа: расход ≥ $20 И цена за результат > $13 → выключить
- LatAm (название содержит BO/PY/CO/EC/PA): расход ≥ $10 И цена за результат > $5 → выключить
