# Перенос рабочей сессии на локальную машину

Здесь лежит всё, что было наработано в облачной сессии Claude Code за 10–19 августа 2026.
Контейнер эфемерный, поэтому содержимое перенесено в репозиторий.

## С чего начать

1. **`CONTEXT.md`** — как устроена работа: движок сторитейла, девять инвариантов воронки,
   батарея проверок, выводы из статистики, незакрытые задачи. Читать первым.
2. **`ops/launch_spec.md`** — регламент запуска и отсечки кампаний. Главнее всего
   остального во всём, что касается рекламы.
3. **`ops/zadanie_dubl_19_08.md`** — незакрытая задача, первая после переезда.

## Структура

| Папка | Что внутри |
|---|---|
| `storytales/` | 39 готовых сторитейлов. Пары RU + языковая версия гео |
| `landings/` | Адаптированные лендинги: `RS/`, `BG/`, `other/` (FR, IE, IN, NG, NL) |
| `creatives/` | Концепты изображений с промптами генерации |
| `hooks/` | Библиотеки хуков, в том числе 100 хуков под ветеринарный лендинг |
| `ops/` | Регламент, аналитика кампаний, идеи заходов, задания |
| `tools/` | Скрипты проверки текстов и сборщики лендингов по гео |
| `uploads/` | 66 исходников, присланных владельцем: лендинги, референсы, тексты |
| `transcript/` | Полный диалог сессии |

## Транскрипт

- **`transcript/dialog.md`** — читаемая версия: 125 сообщений владельца и 182 ответа,
  без служебного вывода инструментов. Это то, что имеет смысл читать глазами.
- **`transcript/session.jsonl.gz`** — полный сырой транскрипт: каждый вызов инструмента,
  каждый результат, вложенные изображения. 28 МБ в распакованном виде.
  Распаковать: `gunzip -k session.jsonl.gz`

## Загруженные файлы

`uploads/` — исходники от владельца с восстановленными читаемыми именами
(в системе они лежали с префиксами вида `4096e745-`). Дубликаты убраны: из 133 файлов
осталось 66 уникальных. Соответствие имён и исходных идентификаторов —
`uploads/_manifest.json`.

**Осторожно:** имена файлов не всегда соответствуют содержимому. Загруженный как
`RSvet.html` на деле оказался лендингом травника. Всегда открывать и смотреть героя.
