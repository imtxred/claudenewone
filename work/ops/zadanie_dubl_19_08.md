# Задание: дубликат кампании RS story sust trav

Вставить целиком в чат на claude.ai с включённым коннектором Facebook ADS.

---

Работай через коннектор Facebook ADS.

**Кабинет:** `huananyoumao-C`, ID рекламного аккаунта `2775699489449002` (в API — `act_2775699489449002`).

**Задача:** создать дубликат кампании `(05 08) RS story sust trav 1 (78013)` со следующими изменениями.

| Параметр | Значение |
|---|---|
| Имя новой кампании | `(19 08) RS story sust trav 1 TEST` |
| Ссылка во всех креативах | `https://lumelu-strong.info/F8fgcgCY` |
| Бюджет | $20/день на каждый адсет (ABO, дневной, на уровне адсета) |
| Отложенный старт | 20.08.2026, 04:00 GMT+3 = `2026-08-20T01:00:00Z` |

Всё остальное копировать с оригинала без изменений.

## Порядок работы

**Кампанию НЕ собирать заново. Дублировать существующую.** Копия переносит ID креативов,
пиксель, атрибуцию и накопленные реакции с комментариями под объявлением — при пересборке
всё это теряется, и объявление стартует без социального доказательства.

1. `ads_get_ad_entities` на уровне campaign — найти оригинал `(05 08) RS story sust trav 1 (78013)`, забрать его ID.
2. **Скопировать кампанию целиком:** `POST /<campaign_id>/copies`, `deep_copy=true`, `status_option=PAUSED`. Никаких «рекомендаций» Facebook не применять — ни Instagram-плейсментов, ни Advantage+ бюджета, ни Advantage+ креатива, ни моментальных форм, ни видео. Они ломают проверенную связку.
3. В копии переименовать кампанию в `(19 08) RS story sust trav 1 TEST`.
4. Выставить `daily_budget` = $20 на каждом адсете.
5. Подменить ссылку **в трёх местах каждого креатива**: `link_data.link`, `link_data.call_to_action.value.link`, и `link` верхнего уровня, если он есть. Проверить, что старый домен не остался нигде.
6. Поставить `start_time = 2026-08-20T01:00:00Z` на адсеты, статус кампании `ACTIVE` (отложенный старт сам держит показы до 04:00).
7. **После любой правки `daily_budget` перепроверить статус адсета.** API принудительно ставит адсет на паузу при изменении бюджета — проверено 19.08 на десяти адсетах. Поднять обратно через `ads_activate_entity` и убедиться, что `effective_status` не `PAUSED`.
8. Сверить с оригиналом, что копия не подхватила ничего лишнего: плейсменты остались `facebook / feed / mobile / mobilefeed`, бюджет остался на адсете (ABO, не CBO).

Если копирование через API недоступно — то же самое руками, кнопкой «Дублировать»
в Ads Manager. Порядок и какие галочки снимать — раздел 1.1 регламента.

## Обязательные параметры (регламент запуска)

**Структура**
- Цель `OUTCOME_LEADS`, оптимизация `OFFSITE_CONVERSIONS`, событие `fb_pixel_lead`
- Стратегия ставки `Highest volume`
- Атрибуция `1d_view / 1d_click / 1d_engaged_view`
- ABO, дневной бюджет на адсете. CBO не использовать

**Возраст:** 25–65. Плюс `expansion_all`, `advantage_audience: 1`, `age = 1`, `gender = 1`. Интересов, LAL и кастомных аудиторий нет.

**Гео:** только RS, режим `home + recent`.

**Плейсменты — критично, вручную:**
```
publisher_platforms:  ["facebook"]
facebook_positions:   ["feed"]
device_platforms:     ["mobile"]
page_types:           ["mobilefeed"]
```
Выключено всё остальное: Instagram, Audience Network, Messenger, desktop, Stories, Reels, Marketplace, Video feeds, Right column, Search. Advantage+ placements не использовать. Brand safety — `RELAXED`.

## После создания

Отчитаться: ID кампании, ID адсетов, ID объявлений, подтверждение подменённой ссылки в каждом креативе, `effective_status` каждого адсета и `start_time`.

## Контекст по маркеру TEST

Кампания создаётся со словом `TEST` в названии — под него подпадают нативные автоправила Facebook:
- расход за всё время ≥ $15 и результатов 0 → пауза
- выключена, расход < $30, результатов 0 → подъём в 04:00 (единственный второй заход)
- расход $30 и снова ноль → выключение навсегда

Тест кампании стоит $30–40, не больше.

Целевой CPL по RS — **$9.26**, порог остановки — **$12**. Кампании не гасить самостоятельно: писать владельцу, решение принимает он (трекер лидов ловит больше конверсий, чем показывает Facebook).
