# Почему не открывалась форма после видео

Файлы: `index.html` (польский слуховой лендинг Ausen) и `js/video.js`.
Исправленный скрипт: `work/landings/PL/video.js`.

## Коротко

К форме вело три дороги. Две были перекрыты, третья открывалась только
у того, кто досмотрел двадцать семь минут до последней секунды.

---

## Причина 1. Крестик не открывал форму. Главная

```js
$('#close').on('click', function() {
    $(this).hide()
    $('#container_video').removeClass('fullscreen')
    document.documentElement.classList.remove('is-locked')
})
```

Обработчик просто выходит из полноэкранного режима. **`showOrder()` он
не вызывает.** Человек закрывает видео крестиком — и не получает ничего.
Это ровно тот сценарий, про который вы написали.

## Причина 2. Попап показывался на 30-й минуте, то есть никогда

В `index.html` стоит настройка:

```html
<script> start = 120; duration = 600; </script>
```

А в `video.js` внутри `$(document).ready` объявлено своё:

```js
let start = 1818;
let duration = 5;
```

`let` внутри функции перекрывает глобальные `start` и `duration` из страницы.
Значения 120 и 600 не применялись никогда. Попап всплывал на **1818-й
секунде — это 30 минут 18 секунд**, а ролик короче. Значит и второй путь
к форме — клик по попапу — был закрыт.

## Причина 3. `video.js` подключён три раза

- строка 15 — `js/video.js?=v1` в `<head>`
- строка 65 — `js/video.js` между `</head>` и `<body>`
- строка 422 — `js/video.js?=v1` перед `</body>`

Строки 15 и 65 — разные URL, браузер грузит и выполняет оба. Все обработчики
навешивались дважды-трижды, а `start_timer()` заводил несколько интервалов,
и обратный отсчёт шёл в два-три раза быстрее реального времени.

## Причина 4. Форма могла оставаться скрытой из-за CSS

`#order` прячется только стилем в `style_3.css`. Если там что-то поехало,
`fadeIn()` отработает, но элемент останется невидимым. В новой версии
форма принудительно скрывается на старте через `$order.hide()`, поэтому
её поведение больше не зависит от того, что написано в CSS.

---

## Что делать

### 1. Заменить `js/video.js` на приложенный

Там же лежит защита от повторной инициализации, так что даже если
вы не станете убирать лишние подключения, скрипт отработает один раз.

### 2. Убрать два лишних подключения в `index.html`

Оставить **только** строку 422, перед `</body>`:

```html
<script src="js/video.js?=v1"></script>
```

Удалить строку 15 (в `<head>`) и строку 65 (между `</head>` и `<body>`).

### 3. Поправить инлайн-настройку

Сейчас:

```html
<script> start = 120; duration = 600; </script>
```

`duration` — это сколько секунд висит попап, а не длина ролика. Шестьсот
секунд означает, что попап не уйдёт десять минут. Разумно так:

```html
<script>
  start = 120;      // попап на 2-й минуте
  duration = 10;    // висит 10 секунд
  showForm = 600;   // форма под видео открывается на 10-й минуте
</script>
```

Этот блок должен стоять **до** подключения `video.js`.

---

## Три вещи рядом, раз уж полез в файл

1. **Два элемента с `id="oneform"`** — `<span>` в строке 87 и `<div>`
   в строке 91. Дубль id, `$('#oneform')` возьмёт только первый.
   Лишний надо удалить.
2. **Цена рендерится как «310 PLN zł»** — в строке 113 внутри
   `<span class="price-old">` написано `310 PLN`, а следом идёт отдельный
   `<span>zł</span>`. Должно быть `<span class="price-old">310</span>`
   и `<span>zł</span>`. То же в строке 114 с `155 PLN`.
3. **`$('a').on('touchend, click', ...)`** — запятая в списке событий.
   jQuery режет строку по пробелам, получается событие с именем `touchend,`.
   Сейчас безвредно, потому что тегов `<a>` на странице нет, но при
   добавлении первой же ссылки тач перестанет работать. Правильно:
   `'touchend click'`.

# Дополнение: версия 2 и стенд

Первая правка форму не открыла. Поэтому я собрал стенд — настоящий Chromium,
тот же `index.html`, теми же тремя подключениями `video.js`, и прогнал все
три пути к форме.

## Что показал стенд

| Скрипт | Действие | CSS | Результат |
|---|---|---|---|
| старый | крестик | обычный | **форма не появляется** |
| старый | конец ролика | обычный | появляется |
| v1 | крестик / конец / попап | обычный | появляется |
| v1 | крестик | `#order{display:none !important}` | **не появляется** |
| v1 | крестик | `.formFb{display:none}` | **не появляется** |

То есть сам скрипт после первой правки работает. Если у вас форма
всё равно не открывается, остаются ровно три причины, и все три — вне
логики скрипта.

## Причина A. Браузер отдаёт старый файл из кэша

`video.js` подключён по двум разным адресам: `js/video.js?=v1` и `js/video.js`.
Вы заменили файл на сервере, а браузер и CDN продолжают отдавать старую
копию — по обоим адресам сразу. Снаружи выглядит как «ничего не изменилось».

**Лечится только сменой версии в адресе.** Замените во всех подключениях
`?=v1` на `?=v2` — тогда это новый URL и кэш к нему отношения не имеет.

## Причина B. Форму прячет CSS сильнее, чем её показывает jQuery

Если в `style_3.css` стоит `#order{display:none !important}` или скрыт
не `#order`, а `.formFb`, то `fadeIn()` отрабатывает вхолостую: элемент
получает inline-стиль, но `!important` из файла его перебивает.

В версии 2 это закрыто: форма и все её родители показываются через
`setProperty('display','block','important')`, то есть поверх любых правил.
На стенде это прошло все враждебные варианты CSS.

## Причина C. Файл лежит не там, куда смотрит страница

Страница грузит `js/video.js`. Если вы положили файл в корень или
в другую папку — подключение молча возвращает 404, и на странице
не работает вообще ничего из этого скрипта.

---

## Что делать по шагам

1. Положить новый `video.js` в **`js/video.js`** рядом с `index.html`.
2. В `index.html` **удалить два лишних подключения** — строку 15 (в `<head>`)
   и строку 65 (между `</head>` и `<body>`). Оставить одно, перед `</body>`,
   и сменить версию:
   ```html
   <script src="js/video.js?=v2"></script>
   ```
3. Поправить инлайн-настройку и поставить её **выше** подключения:
   ```html
   <script>
     start = 120;      // попап на 2-й минуте
     duration = 10;    // висит 10 секунд
     showForm = 600;   // форма открывается на 10-й минуте
   </script>
   ```
4. Открыть страницу с жёсткой перезагрузкой: Ctrl+F5, на телефоне —
   в режиме инкогнито.

## Если и после этого не откроется

Откройте лендинг с добавкой **`?debug=1`** в адресе:

```
https://ваш-домен/index.html?debug=1
```

Внизу появится чёрная плашка с зелёным текстом. Она пишет, запустился ли
скрипт, нашёл ли он элементы, какие настройки подхватил, был ли клик
и какой высоты получилась форма. Пример нормальной работы:

```
video.js v2 запущен
найдено: video=1 play=1 popup=1 close=1 order=1
настройки: start=120 duration=10 showForm=600
повторное подключение video.js — пропущено
клик по крестику
форма показана, высота = 297px
```

Пришлите мне скриншот этой плашки — по ней сразу видно, где обрывается.
Если плашки нет вообще, значит страница грузит старый файл или не грузит
его совсем, и дело в пунктах A или C.

## Что ещё добавлено в версии 2

- **Подстраховка скроллом.** Если человек не стал смотреть видео, а просто
  пролистал страницу ниже плеера, форма открывается сама.
- Логи всех трёх путей и предупреждение, если форма показалась, но её
  высота близка к нулю, — это уже чистая вёрстка формы.

# Дополнение: версия 3 — окно по центру экрана

Раньше форма просто проявлялась под видео: человек закрывал ролик
и оставался на той же странице, где форму ещё надо было заметить.
Теперь она открывается модальным окном **по центру экрана**, фон
за ним затемняется, страница под ним не прокручивается.

## Как это устроено

Скрипт сам создаёт `<div id="orderModal">` и переносит в него **саму
форму `#order`**, а не её копию. Значит, `name`, `action`, скрытые поля,
`sid`, пиксель и все обработчики отправки остаются те же — ничего
дублировать и переподключать не надо. При закрытии окна форма
возвращается на прежнее место под видео и остаётся доступной.

Параметры окна: затемнение `rgba(0,0,0,.65)`, лёгкое размытие фона,
белая карточка шириной до 440 px, скругление 14 px, выезд снизу за
0,22 с, `z-index` 2147483000 — выше любого элемента лендинга.
Если форма выше экрана, карточка упирается в 92 % высоты и внутри
неё появляется своя прокрутка; тело страницы при этом заблокировано,
фон не «уезжает» под пальцем.

## Что открывает окно, а что нет

| Событие | Что происходит |
|---|---|
| крестик на видео | **окно по центру** |
| ролик досмотрен до конца | **окно по центру** |
| клик по попапу | **окно по центру** |
| 10-я минута просмотра (`showForm`) | форма проявляется **под видео**, окно не всплывает |
| скролл ниже плеера | форма проявляется **под видео** |

Это сделано намеренно. Пока человек смотрит, окно закрывать ему
видео не должно — оно перекрыло бы ролик посреди просмотра.

## Крестик в углу окна

По умолчанию он есть. Если хотите окно без выхода — добавьте в
инлайн-настройку `index.html`:

```html
<script>
  start = 120;
  duration = 10;
  showForm = 600;
  modalClosable = false;   // окно без крестика
</script>
```

Клик по затемнённому фону окно не закрывает — это сделано специально,
чтобы случайное касание мимо формы не сбрасывало заявку.

## Проверено на стенде

Настоящий Chromium, тот же `index.html`, все три подключения `video.js`.

| Действие | Враждебный CSS | Результат |
|---|---|---|
| крестик | обычный | окно по центру, отклонение от центра 0 px |
| конец ролика | обычный | то же |
| клик по попапу | обычный | то же |
| крестик | `#order{display:none !important}` | окно открывается |
| конец ролика | `#order{display:none !important}` | окно открывается |
| крестик | `.formFb{display:none !important}` | окно открывается |
| крестик | `#container_video{display:none}` | окно открывается |
| крестик | `.formFb__container{visibility:hidden}` | окно открывается |
| ничего не делать | обычный | окно закрыто, само не всплывает |

Затемнение фона везде `rgba(0, 0, 0, 0.65)`, `z-index` 2147483000,
прокрутка страницы заблокирована. Экраны: 1440×900, 420×860, 360×640
и нарочно низкий 412×380 — на последнем карточка упёрлась в 92 % высоты
и получила внутреннюю прокрутку, как и задумано. Крестик во всех случаях
возвращает форму под видео.

## Что сделать у себя

1. Положить новый `video.js` в `js/video.js`.
2. Сменить версию в подключении, иначе браузер отдаст старый файл
   из кэша:
   ```html
   <script src="js/video.js?=v3"></script>
   ```
3. Остальное — как в шагах выше: одно подключение перед `</body>`,
   инлайн-настройка над ним, жёсткая перезагрузка Ctrl+F5.

Если что-то пойдёт не так, `?debug=1` работает и здесь: плашка пишет
«модальное окно открыто, высота формы = … px».
