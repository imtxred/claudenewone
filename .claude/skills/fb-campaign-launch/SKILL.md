# Запуск кампании в Facebook

**Кампания никогда не собирается с нуля. Всегда копия рабочей.**

Копия переносит ID креативов, пиксель, атрибуцию, параметр URL для трекера и накопленные
реакции с комментариями под объявлением. Сборка заново теряет всё это: объявление стартует
с нулевым социальным доказательством, а поле параметра URL приходится заполнять руками
и есть шанс ошибиться в пикселе.

Три шага: **дубль → правки в черновике → «Опубликовать».**

---

## Шаг 1. Дубль

Кнопка **«Дублировать»** на кампании-доноре. Донором берётся кампания с похожей связкой,
которая уже крутилась.

### Диалог «Продублируйте кампанию»

**Снять ВСЕ галочки, включая верхнюю «Применить рекомендации».** Facebook рисует рядом
зелёные обещания вида «снижение цены за результат на 23%» — это его модель, а не наши
данные. Каждая рекомендация ломает проверенную связку:

| Рекомендация | Что ломает |
|---|---|
| Места размещения в Instagram | правило «только `facebook / feed / mobile`» |
| Параметр Advantage+ для бюджета | переводит на CBO, а мы работаем на ABO |
| Сайт и моментальные формы | меняет тип конверсии и точку замера |
| Добавить видео | меняет креатив, который и есть предмет теста |
| Креатив Advantage+ | отдаёт алгоритму кадрирование, текст и наложения |

### Диалог «Дублировать кампанию»

- Число копий — **1**
- **«Показывать существующие реакции, комментарии и репосты в новых объявлениях» — оставить включённой.** Ради неё всё и затевается
- «Создать А/В-тестирование» — **не включать**
- Нажать «Дублировать»

Копия создаётся **черновиком** и в аукцион не уходит, пока не нажата «Опубликовать».

---

## Шаг 2. Правки в черновике

Всё правится пачкой, до публикации.

### Уровень кампании

**Название:** `(ДД ММ) ГЕО тип вариант (метка) TEST`

Маркер `TEST` обязателен для новой кампании — под него настроены нативные автоправила.

### Уровень адсета

| Что | Значение |
|---|---|
| Гео | одна страна. `home + recent` для RS, `frequently_in + home + recent` для остальных |
| Бюджет | **$20/день**, ABO |
| Время запуска | отложенный старт, обычно 04:00 GMT+3 |

⚠ **Меняешь гео — меняй префикс страны в названии кампании.** Нативное правило отсечки
для Латинской Америки отбирает кампании по вхождению кода страны в имя. Мексиканская
кампания с префиксом `RS` попадёт под европейский порог $13 вместо $5 и будет жечь
бюджет втрое дороже цели, пока это не заметят глазами.

Проверить, что дубль не подхватил лишнего: плейсменты остались
`facebook / feed / mobile / mobilefeed`, бюджет остался на адсете, возраст 25–65.

### Уровень объявления

**Ссылка.** Подменить в основном поле. Отдельно проверить **ссылку в кнопке призыва
к действию** — она хранится отдельно и часто остаётся старой.

**Креатив.** Изображение и текст, если меняем связку.

**Снять галочку «Объявления в рекламном блоке с несколькими рекламодателями».**
Формулировка Facebook: «Ваше объявление может появляться вместе с другими объявлениями
в одном рекламном блоке, чтобы его было проще находить. Рекламный креатив можно
масштабировать или обрезать». Второе предложение и есть причина: наши креативы несут
текст и лица, обрезка их убивает.

**Улучшения креатива Advantage+ — все выключены, состояние `0/4`:**
добавление оверлеев, улучшение визуальных элементов, улучшение текста и ещё одно.

**Ключевые улучшения — все выключены, состояние `0/3`:**
актуальные комментарии, улучшите призыв к действию, настройка яркости и контрастности.

Кнопку «Попробуйте» рядом с ними не нажимать. Если в интерфейсе видно `0/4` и `0/3` —
всё правильно.

**Параметр URL** — в самом низу уровня объявления:

```
adaccount_id={{adaccount.id}}&fbpx=PIXEL_ID&campaign_id={{campaign.id}}&adset_id={{adset.id}}&ad_id={{ad.id}}&adset_name={{adset.name}}&ad_id={{ad.id}}
```

Вместо `PIXEL_ID` — ID пикселя кампании. **На кабинет используется один и тот же пиксель**,
так что значение меняется от кабинета к кабинету, а не от кампании к кампании.

Пример для пикселя `1010385875152619`:

```
adaccount_id={{adaccount.id}}&fbpx=1010385875152619&campaign_id={{campaign.id}}&adset_id={{adset.id}}&ad_id={{ad.id}}&adset_name={{adset.name}}&ad_id={{ad.id}}
```

При дублировании поле **уже заполнено** — надо только убедиться, что пиксель в нём
соответствует кабинету. Заполнять с нуля приходится лишь при сборке заново, и это ещё
одна причина не собирать заново.

---

## Шаг 3. Опубликовать

Одна кнопка в конце, после всех правок. До неё ничего не откручивается.

**Принудительная пауза при правке бюджета — проблема только API.** В ручном потоке
правки идут в черновике, публикация одна, адсет выходит сразу в нужном состоянии.
Перепроверять `effective_status` надо только когда бюджет правится через API
у уже опубликованной кампании.

---

## Чек-лист перед публикацией

- [ ] Название с маркером `TEST`, префикс страны совпадает с гео на адсете
- [ ] Гео — одна страна
- [ ] Бюджет $20/день на каждом адсете, ABO
- [ ] Отложенный старт выставлен
- [ ] Плейсменты: `facebook / feed / mobile / mobilefeed`, всё остальное выключено
- [ ] Возраст 25–65
- [ ] Ссылка подменена в основном поле **и в кнопке CTA**
- [ ] Галочка «несколько рекламодателей» снята
- [ ] Улучшения креатива `0/4`, ключевые улучшения `0/3`
- [ ] Параметр URL на месте, пиксель в нём соответствует кабинету
- [ ] Ни одна рекомендация Facebook не применена

---

## Через API

`POST /<campaign_id>/copies` с `deep_copy=true` и `status_option=PAUSED`, затем правки
в копии. Не создавать кампанию, адсеты и объявления по отдельности — дороже и теряет
социальное доказательство и заполненный параметр URL.

После правки `daily_budget` через API — включить адсет обратно и проверить
`effective_status`.

## Что дальше

Кампания создаётся с маркером `TEST`. Под него настроены нативные автоправила:
$15 без результата → пауза, один второй заход в 04:00, второй ноль → выключение
навсегда. Тест кампании стоит $30–40, не больше.

Целевые CPL по гео и пороги остановки — таблица в `work/ops/launch_spec.md`.

**Кампании по своей инициативе не гасить.** Трекер ловит больше конверсий, чем
показывает Facebook, поэтому высокий CPL в кабинете не равен убытку. Видишь проблему —
пиши владельцу, решение принимает он.
