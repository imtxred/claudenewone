# Почему не открывалась форма после видео

Файлы: `index.html` (польский слуховой лендинг Ausen) и `js/video.js`.
Исправленный скрипт: `work/landings/PL/video.js`.

## Коротко

К форме вело три дороги. Две были перекрыты, третья открывалась только
у того, кто досмотрел двадцать семь минут до последней секунды.

---

## Причина 1. Крестик не открывал форму. Главная

```js
$('#close').on('click', function() {
    $(this).hide()
    $('#container_video').removeClass('fullscreen')
    document.documentElement.classList.remove('is-locked')
})
```

Обработчик просто выходит из полноэкранного режима. **`showOrder()` он
не вызывает.** Человек закрывает видео крестиком — и не получает ничего.
Это ровно тот сценарий, про который вы написали.

## Причина 2. Попап показывался на 30-й минуте, то есть никогда

В `index.html` стоит настройка:

```html
<script> start = 120; duration = 600; </script>
```

А в `video.js` внутри `$(document).ready` объявлено своё:

```js
let start = 1818;
let duration = 5;
```

`let` внутри функции перекрывает глобальные `start` и `duration` из страницы.
Значения 120 и 600 не применялись никогда. Попап всплывал на **1818-й
секунде — это 30 минут 18 секунд**, а ролик короче. Значит и второй путь
к форме — клик по попапу — был закрыт.

## Причина 3. `video.js` подключён три раза

- строка 15 — `js/video.js?=v1` в `<head>`
- строка 65 — `js/video.js` между `</head>` и `<body>`
- строка 422 — `js/video.js?=v1` перед `</body>`

Строки 15 и 65 — разные URL, браузер грузит и выполняет оба. Все обработчики
навешивались дважды-трижды, а `start_timer()` заводил несколько интервалов,
и обратный отсчёт шёл в два-три раза быстрее реального времени.

## Причина 4. Форма могла оставаться скрытой из-за CSS

`#order` прячется только стилем в `style_3.css`. Если там что-то поехало,
`fadeIn()` отработает, но элемент останется невидимым. В новой версии
форма принудительно скрывается на старте через `$order.hide()`, поэтому
её поведение больше не зависит от того, что написано в CSS.

---

## Что делать

### 1. Заменить `js/video.js` на приложенный

Там же лежит защита от повторной инициализации, так что даже если
вы не станете убирать лишние подключения, скрипт отработает один раз.

### 2. Убрать два лишних подключения в `index.html`

Оставить **только** строку 422, перед `</body>`:

```html
<script src="js/video.js?=v1"></script>
```

Удалить строку 15 (в `<head>`) и строку 65 (между `</head>` и `<body>`).

### 3. Поправить инлайн-настройку

Сейчас:

```html
<script> start = 120; duration = 600; </script>
```

`duration` — это сколько секунд висит попап, а не длина ролика. Шестьсот
секунд означает, что попап не уйдёт десять минут. Разумно так:

```html
<script>
  start = 120;      // попап на 2-й минуте
  duration = 10;    // висит 10 секунд
  showForm = 600;   // форма под видео открывается на 10-й минуте
</script>
```

Этот блок должен стоять **до** подключения `video.js`.

## Три вещи рядом, раз уж полез в файл

1. **Два элемента с `id="oneform"`** — `<span>` в строке 87 и `<div>`
   в строке 91. Дубль id, `$('#oneform')` возьмёт только первый.
   Лишний надо удалить.
2. **Цена рендерится как «310 PLN zł»** — в строке 113 внутри
   `<span class="price-old">` написано `310 PLN`, а следом идёт отдельный
   `<span>zł</span>`. Должно быть `<span class="price-old">310</span>`
   и `<span>zł</span>`. То же в строке 114 с `155 PLN`.
3. **`$('a').on('touchend, click', ...)`** — запятая в списке событий.
   jQuery режет строку по пробелам, получается событие с именем `touchend,`.
   Сейчас безвредно, потому что тегов `<a>` на странице нет, но при
   добавлении первой же ссылки тач перестанет работать. Правильно:
   `'touchend click'`.
